## O que a biblioteca inteira concorda

Cinco pontos aparecem em tópicos independentes, com palavras diferentes. É o núcleo real.

1. **Venda antes de construir.** Entregue manual antes de automatizar. *"Você é pago para aprender o
   processo. Só depois de aprender, você automatiza."*
2. **Nichar não é opcional.** "Agente de IA" não vende. "Agente de IA para clínica odontológica
   agendar no WhatsApp" vende. O mesmo vale para infoproduto, SaaS e criativo.
3. **O lucro está na esteira, não no primeiro produto.** Order bump, upsell, recorrência, manutenção.
   Quem lucra só no front é exceção.
4. **Distribuição é o negócio inteiro.** Construir virou barato e fácil. Conseguir cliente não.
5. **O que satura é o criativo/ângulo, não a oferta.** Vale para anúncio, para conteúdo e para nicho.

## A biblioteca

```
references/youtube/
  urls.txt      # links brutos
  index.json    # status de cada vídeo
  {canal}/{título}.md   # transcrição com timestamps
```

168 vídeos, 30+ canais, ~170 horas. Cada afirmação nos guias é rastreável ao vídeo e timestamp de origem.

> **Aviso de confiabilidade.** As transcrições são legendas automáticas. Números e nomes de ferramentas
> vêm corrompidos com frequência (`"cloud"`=Claude, `"Lovbow"`=Lovable, `"QFi"`=Kiwify, `"Moca"`=Mocha).
> Onde um número é suspeito, está marcado ⚠️ no guia correspondente.

Para adicionar vídeos: cole os links aqui no chat, ou em `references/youtube/urls.txt` e rode a skill
`youtube-refs`.
